    Installation

    1. Create a Discord app

      Enable Guild Install with the applications.commands scope. Use the install link to add the app to a server you administer.

    2. Add your Discord credentials

      Copy the Application ID and Public Key from General Information, and the token from Bot. Save all three in the Freecode setup card and publish your site.

    3. Connect Discord and try a command

      In General Information, set the Interactions Endpoint URL to your published endpoint and save. Roll Call registers its commands when Discord verifies the endpoint. Try /ping in your server.
