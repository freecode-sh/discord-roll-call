Set up Roll Call.

Run your own copy on a Worker. The starter acknowledges check-ins without storing them, so you can add a history or a daily count as your first change.

  1. Create a Discord app.Use the Discord Developer Portal and enable Guild Install with applications.commands.
  2. Deploy the Worker.Set DISCORD_PUBLIC_KEY in your Worker’s environment. Set the Interaction Endpoint URL to your Worker’s /interactions route.
  3. Register the commands.Set your app ID and bot token locally, run npm run register, and try /check-in in your server.
