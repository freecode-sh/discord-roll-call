    Installation

    1. Create a Discord app

      Enable Guild Install with the applications.commands scope. Use the install link to add the app to a server you administer.

    2. Set the public key and publish

      Copy the Public Key from General Information in Discord. Save it as DISCORD_PUBLIC_KEY in Freecode and publish your site. Set the Discord Interactions Endpoint URL to your published site’s /interactions route.

    3. Register and test the slash commands

      Copy discord-register.env.example to .env.register on your computer. Add your Application ID and bot token, then run npm run register. Try /ping in your Discord server.
